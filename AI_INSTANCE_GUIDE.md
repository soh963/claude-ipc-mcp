# Guide for Actual AI Instance Communication

## For codex and lm AI CLIs

Since codex and lm are actual AI command-line interfaces, they need to:

### 1. Register with the IPC system
```bash
# In codex CLI:
python tools/ipc_register.py codex

# In lm CLI:
python tools/ipc_register.py lm
```

### 2. Check for messages
```bash
# In codex CLI:
python tools/ipc_check.py codex

# In lm CLI:
python tools/ipc_check.py lm
```

### 3. Process the message and generate a response
When they see the weather inquiry, they should use their AI capabilities to:
- Understand the question about Seoul weather
- Generate an appropriate response (they can use their knowledge or web search)
- Send the response back

### 4. Send the response back
```bash
# In codex CLI (example response):
python tools/ipc_send.py codex claude "Based on current weather data, Seoul is experiencing [actual weather conditions]. The temperature is approximately [X]°C with [weather description]."

# In lm CLI (example response):
python tools/ipc_send.py lm claude "The weather in Seoul today is [actual conditions]. Current temperature: [X]°C, with [additional details]."
```
